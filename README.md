This repository provides a Python generator for the supply chain benchmark described in [Modelling and Analysis of Supply Chains using Product Timed Petri Nets].


# SupplyChain

SupplyChain is a repository containing a python script and the end-of-line net.

## Usage

```bash
python3 genSupply.py
```

The script will ask for a number of supplier and the higher bound of the manager net generated.

For several managers, you need to manually add a token to the starting place in Manager.net.
